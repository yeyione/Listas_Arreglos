Descripción de la actividad

En esta actividad, exploraremos las diferencias entre el Document Object Model (DOM) y el Browser Object Model (BOM) en JavaScript. El DOM es una representación estructurada del contenido de una página web, permitiendo a los desarrolladores manipular elementos HTML y sus atributos. Por otro lado, el BOM proporciona acceso a las funcionalidades del navegador, como la gestión de ventanas, historial y URL. A través de un cuadro comparativo y una lista interactiva de ciudades, entenderemos mejor cómo estos dos modelos trabajan juntos para crear experiencias web dinámicas.

Cuadro-Comparativo: DOM vs BOM

Característica DOM BOM
Definición El DOM es una representación estructurada del documento HTML como un árbol de objetos. Es una interfaz de programación que permite a JavaScript acceder y manipular el contenido, estructura y estilos de una página web. El BOM es una interfaz que permite a JavaScript interactuar con el navegador en sí mismo, más allá del contenido del documento. No hay un estándar oficial, pero los navegadores modernos lo implementan de manera similar.
Que Controla El contenido del documento HTML -elementos, atributos, textos, estilos, css, etc. Las funcionalidades del navegador-ventana, navegación, historial, ubicación, almacenamiento, etc
Objetivo principal
  • Acceder y modificar elementos HTML
  • Cambiar contenido, estilos y atributos
  • Responder a eventos del usuario
  • Actualizar la pagina sin recargarla
  • Controlar y obtener información del navegador
  • Manipular la ventana del navegador
  • Gestionar la navegación y el historial
  • Acceder adatos del entorno del usuario
Estandarización Estandarizado por el W3C No está estandarizado oficialmente
Alcance El alcance del DOM es el contenido del documento HTML. El alcance del BOM es el entorno del navegador.
